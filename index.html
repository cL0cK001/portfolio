1. Hurry Up（2人協力型2D縦スクロールアクションゲーム）

概要

ネットワーク通信による2人協力型の2D縦スクロールアクションゲームです。
制限時間内に2人で協力し、コミュニケーションを取りながら、最上部を目指そう！

自分の役割

メインプログラマー
ネットワーク通信担当2名、デザイナー1名、メインプログラマー1名の4名体制で開発。キャラクターの移動・アクション挙動、当たり判定（衝突判定）、縦スクロール描画処理、マップデータの構築など、ゲームの根幹を担う主要システムの開発を担当しました。

使用技術・開発環境
C言語 SDLライブラリ Linux ソケット通信
面白くしたポイント
  • 2人の協力が不可欠なゲーム進行：互いにコミュニケーションを取り合って進行する連携設計
  • 迫りくるタイマーとHP共有によるハラハラ感：制限時間とHP共有が生み出すスリルと緊張感
  • レバー操作による協力ギミック：レバーを切り替えてステージの仕掛けを動かし、2人で相互に操作し合いながら道を切り拓く仕掛け
技術的な工夫
  • モジュール分割による可読性の向上：ヘッダー、メイン処理、キャラクターデータ、マップデータ等を分離し可読性を向上
  • 高精度な当たり判定の実装：判定を上半身と下半身に分割して精度を上げ、壁のすり抜け現象を防止
  • 自プレイヤー追従の画面スクロール：通信相手ではなく「自分の操作キャラクター」の動きに合わせて画面が縦スクロールする追従機能
制作中（5月〜）

2. Odd Odds（PC向けローグライク×ギャンブルゲーム）

概要

「ローグライク×ギャンブル」をコンセプトとしたPC向けゲーム。UFOキャッチャーやピンボールで資金を稼ぎ、数ターンごとに迫る借金の返済を持ちこたえよう！毎ターン行えるアームの強化や速度アップといったローグライク要素を活用したり、数ターンごとに発生する訪問者イベントを進めながら目標金額の返済を目指すゲームです。

自分の役割

UFOキャッチャーシステムの設計・開発
プログラマー4名でゲームの主要4システムをそれぞれ分担して開発を進めており、私はUFOキャッチャーのシステムを担当しています。アームの移動・昇降・掴み動作の物理判定から、UI実装、オブジェクト作成、毎ターンのアーム機能・速度等のアップグレード実装まで、設計・開発を行っています。

UFOキャッチャーシステムの開発進捗

2. コインをつかめるように
3. 挙動・デザイン改善（現在）
※ここからさらに、ユーザーが操作していて気持ちよく・楽しくなる要素を追加していく予定です。
使用技術・開発環境
Unity C# Blender GitHub
面白くしたポイント
  • ルーレット機能によるワクワク感とランダム性の創出：プレゼントボックスを落とし口へ入れるとルーレットが回転し、当選したアイテムが上空から降り注ぐ演出・ギミックを実装。ギャンブルならではの胸が高鳴るランダム要素を追加
  • アーム操作の手触りと掴んだ瞬間の爽快感の追求：コインを掴み取る際の物理挙動や操作感にこだわり、直感的で心地よい手応えとプレイの爽快感を追求
  • 特定アイテム落下時のライト演出：特定のアイテムが落下する際にライト演出を挟むことで、何が手に入っているかを可視化し、期待感を強化

  • UFOキャッチャーの物理挙動・掴み動作のリアリティ追求：アーム移動時の自然な揺れ挙動や、コインを掴みあげる物理判定ロジックにこだわり、本物のキャッチャー機のようなリアルな操作感を再現

3. ミサイル避難VRシミュレータ（学士時代の研究制作）

概要

徳島大学理工学部キャンパスをVR空間上に再現した「Tokudiverse」を基盤に開発した、緊急時の避難行動を体験・学習できるVRシミュレータです。
Jアラートの発令とともに避難を開始し、到達地点で避難完了パネルを操作します。危険な場所や不適切な行動をとっている場合は適切な安全行動を促す指示・警告が表示され、安全な状態を確保して避難を完了するとミサイル着弾演出が発生。着弾後の被害状況を確認して体験終了となる、防災意識向上と適切な安全行動の定着を目指したシステムです。

使用技術・開発環境
Unity C# VR (Meta Quest) Blender
研究のポイント・技術的工夫
  • 精密な3D空間再現とログ収集：大学キャンパスおよび避難空間をVR空間上に精密に再現。被験者の移動軌跡や視線ログをリアルタイムで収集・分析する仕組みを構築しました。
  • 避難姿勢・頭部保護行動の自動判定ロジック：コントローラーの高さから「しゃがみ姿勢」を判定し、さらにコントローラーと頭部（HMD）の位置関係から「頭部保護動作」を判定する判定機能を実装。適切な安全行動の例を以下の画像に示します。
